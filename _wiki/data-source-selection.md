After having installed the application, you're finally ready to use it!

Sniffnet's initial page displays different options to configure the network traffic analysis before actually starting to capture data. <br>
The first option we focus on is the **selection of the data source**, visible in the left portion of the page.

<div align="center">
<img alt="Sniffnet data source selector for choosing a network adapter or capture file" width="80%" src="{{ '/assets/img/wiki/clip_capture_source.png' | relative_url }}">
</div>

Sniffnet supports two alternative sources to capture traffic data from:
1. [network adapters](#network-adapters)
2. [PCAP files](#pcap-files)

Let's examine them one by one.

## Network adapters

The first option is to capture traffic data from one of the **network adapters** available on your machine. <br>
This is the most common way to use Sniffnet, as it allows you to monitor **real-time** traffic data flowing in and out of your computer.

In the left portion of the page you can find a scrollable column containing the **list of all the available network adapters** on your machine. <br>
This list is **dynamically kept up to date**: this means that if you disconnect one of the adapters or bring up a new one, the relative changes will be reflected here.

Each item of the list is a device (either physical or virtual) from which data will be captured and analysed by Sniffnet. <br>
For each entry are reported:
- its **name** and/or **description**
- the list of all its active **IPv4** and **IPv6** **addresses**
- a **chart** showing a preview of the traffic exchanged by that adapter during the past 30 seconds

The currently selected adapter has its borders highlighted, and you can select a different one simply by clicking on the corresponding entry.

By **default**, Sniffnet will select the adapter that's marked as the main network interface by the system, but this is not guaranteed to be the traffic source you actually want to inspect.<br>
Typically, you'll want to inspect your Ethernet adapter, which is the one exchanging most of the traffic _incoming to_ or _outgoing from_ your machine.

>
> Sniffnet sorts the list of network adapters according to their recent traffic volume: this way you can find the most active ones at the top of the list.
{: .wiki-callout .wiki-callout-tip data-callout-label="TIP"}

In case the default adapter is not what you meant to inspect, **Sniffnet will remember your selection** so that when you restart again the app you won't have to worry about this aspect any longer.


## PCAP files

An alternative way to use Sniffnet is to analyse network data stored in a file. <br>
**PCAP** (Packet Capture) is a file format used to store network traffic, and it can be generated by various tools such as _Wireshark_ or _tcpdump_.<br>
Sniffnet can read PCAP files and display the captured data in a user-friendly way, allowing you to analyse **past network activity**.

Select "Capture file" from the dropdown, and a button to import such kind of files will appear:

<div align="center">
<img alt="Sniffnet button for importing a PCAP capture file" width="40%" src="{{ '/assets/img/wiki/import_pcap.png' | relative_url }}">
</div>

Clicking on it will open a selection dialog, allowing you to choose a PCAP file from your local filesystem.

>
> The following sections of the Wiki will focus on the usage of Sniffnet with network adapters as data source, since it's the most common way to use the app. <br>
> However, the same concepts are applicable to PCAP files as well, with the only difference that instead of referring to real-time network data, it would be about previously captured traffic that was saved in a file.
